# Public Datasets - Manuel Castillo

Este es un espacio público para almacenar y compartir conjuntos de datos utilizados en mis investigaciones y proyectos.

## Acceso a los Datos

Cualquier archivo subido a esta carpeta estará disponible públicamente a través de la siguiente URL:

`https://manuelcastillos.github.io/manuel_oce_castillo/data/datasets/{nombre_del_archivo}`

## Instrucciones para Subir Datos

1. Coloca tus archivos de datos (CSV, JSON, PDF, etc.) en esta carpeta: `d:\Proyectos_atigravity\web_personal\data\datasets\`
2. Ejecuta el archivo `SUBIR_PERSONAL.bat` en la raíz del proyecto para sincronizar los cambios con GitHub.
